# つながる！さんすうクエスト 🗡️

**▶ あそぶ： https://happy-field-edu.github.io/sansu-quest/**

小学1〜6年生の算数の**系統性**を体感できる、RPG風学習ゲームのプロトタイプです。
「1年生のたしざんが、6年生の分数をたおす武器になる」——学年をこえた知識のつながりを、冒険・装備・ボス戦で見える化します。

## あそび方

1. **4つのワールド**（数と計算・量と測定・図形・数量関係）を選ぶ
2. 各ワールドは**ドラクエ風の3Dフィールド**。「たしざんの村」から「文字式の城」まで、1年生→6年生のゾーンがひとつづきの大地になっている
3. **WASD / 矢印キー**でゆうしゃを動かし、フィールドをうろつく**モンスターシンボル**（単元の記号を浮かべたスライムたち）にぶつかると**エンカウント**→戦闘へ
4. れんしゅうモンスター（5問正解）にかつと、その単元の**そうび**がドロップ
5. 各ゾーンの出口は**大ボス**が門番をしている。たおすと次の学年への門がひらく。大ボスは基本「50問正解」が条件。ただし——

## コアシステム：がんばりがボス戦をラクにする

```
ボスにひつような正解数 = 50 − (レベル ＋ そうびのこうげき力)   ※さいてい25問
```

- これまでの単元をやり込む → レベルと装備が強くなる → ボスが「40問」「30問」でたおせる
- まちがえるとダメージ（防具の「まもり」で軽減）。HPがなくなると失敗だが、稼いだEXPは残る

## 技術スタック

- Vite + React 19 + TypeScript
- **2Dトップダウン（ドラクエ風）**：グリッド移動のタイルマップ、黒×白枠のコマンドウィンドウ、
  1文字ずつのメッセージ表示、フロントビュー戦闘（3Dライブラリ不使用・約300KBの軽量ビルド）
- TailwindCSS v4
- 問題は**単元×技能別のジェネレータ**で自動生成（24単元・115技能。例：小数→たし算／ひき算／0.1がなんこ／大小くらべ／数直線）／セーブは localStorage
- 戦闘画面には「🎯 めあて：数直線」のように**いま試されている技能**を表示。ボス戦は全技能まぜこぜの「まとめテスト」

## 開発

```bash
npm install
npm run dev   # http://localhost:5173
```

## 構成

```
src/
├── data/worlds.ts      # 4ワールド×6学年のステージ定義（敵・ボス・単元のつながり）
├── data/items.ts       # 装備24種
├── data/generators.ts  # 単元別問題ジェネレータ
├── game/logic.ts       # レベル・EXP・ボス必要問題数の計算
├── game/store.tsx      # セーブデータ管理
├── field/              # 3Dフィールド（config: ゾーン・テーマ / Scene: 地形・衝突判定 /
│                       #   Monster: うろつきAI / Field3D: HUD・エンカウント演出）
└── screens/            # Title / WorldSelect / Battle / Equip
```
