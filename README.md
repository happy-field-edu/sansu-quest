# つながる！さんすうクエスト 🗡️

小学1〜6年生の算数の**系統性**を体感できる、RPG風学習ゲームのプロトタイプです。
「1年生のたしざんが、6年生の分数をたおす武器になる」——学年をこえた知識のつながりを、冒険・装備・ボス戦で見える化します。

## あそび方

1. **4つのワールド**（数と計算・量と測定・図形・数量関係）を選ぶ
2. 各ワールドは **1年生→6年生のツリー**。前の学年のボスをたおすと次の学年がひらく
3. **れんしゅうバトル**（5問正解）にかつと、その単元の**そうび**がドロップ
4. **大ボスせん**は基本「50問正解」が条件。ただし——

## コアシステム：がんばりがボス戦をラクにする

```
ボスにひつような正解数 = 50 − (レベル ＋ そうびのこうげき力)   ※さいてい25問
```

- これまでの単元をやり込む → レベルと装備が強くなる → ボスが「40問」「30問」でたおせる
- まちがえるとダメージ（防具の「まもり」で軽減）。HPがなくなると失敗だが、稼いだEXPは残る

## 技術スタック

- Vite + React 18 + TypeScript
- TailwindCSS v4
- 問題はステージ別ジェネレータで自動生成（24単元）／セーブは localStorage

## 開発

```bash
npm install
npm run dev   # http://localhost:5173
```

## 構成

```
src/
├── data/worlds.ts      # 4ワールド×6学年のステージ定義（敵・ボス・単元のつながり）
├── data/items.ts       # 装備24種
├── data/generators.ts  # 単元別問題ジェネレータ
├── game/logic.ts       # レベル・EXP・ボス必要問題数の計算
├── game/store.tsx      # セーブデータ管理
└── screens/            # Title / WorldSelect / WorldMap / Battle / Equip
```
